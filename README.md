Course materials and live-coding examples for **DE0824 Web Development** at Riga Technical University (RTU), DITEF.

The course introduces the foundations of the modern Web platform through practical work with **HTML, CSS, JavaScript, browser developer tools, Git, and GitHub**. Most topics are developed incrementally during live-coding sessions, so the exact pace may change during the semester.

## Approximate syllabus

The following schedule is based on the Fall 2025 course and is **subject to adjustment** according to student progress and the needs of the class.

| Week | Main topics |
| --- | --- |
| 1 | Course introduction; how the Web works; development environment; browser developer tools; first HTML page; Git/GitHub workflow |
| 2 | HTML basics: document structure, elements, attributes, headings, paragraphs, links, images, lists |
| 3 | More HTML: semantic structure, tables, forms, relative and absolute URLs, accessibility basics |
| 4 | CSS basics: selectors, declarations, cascade, inheritance, colors, typography, spacing |
| 5 | CSS box model, sizing, positioning, and layout fundamentals |
| 6 | Responsive design, media queries, and Flexbox |
| 7 | CSS Grid, pseudo-classes, and further responsive layout practice |
| 8 | CSS transitions, transforms, animations; brief introduction to using external web resources/libraries |
| 9 | JavaScript basics: values, types, variables, expressions, operators, console and debugging |
| 10 | Comparisons, logical operators, conditionals, and branching |
| 11 | `switch`, `while`, and `for` loops; repeated processing and debugging control flow |
| 12 | Functions; introduction to the DOM; selecting and modifying page content; browser events |
| 13 | Arrays; DOM input events; processing collections of data and updating the page |
| 14 | JavaScript objects, JSON, event targets, and integration of HTML/CSS/JavaScript concepts |

## Course approach

The course emphasizes understanding the Web platform itself rather than framework-specific development. Examples normally use vanilla HTML, CSS, and JavaScript and are designed to run directly in a modern browser without a build step.

Typical sessions combine a short explanation with instructor-led live coding, browser inspection, debugging, modifications, and small exercises. Git and GitHub are used throughout the course for storing and publishing work.
