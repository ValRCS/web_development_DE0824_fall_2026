## Web Development Learning Resources

The following resources support the DE0824 Web Development course. Students are encouraged to use them for additional reading, practical exercises, and reference. The course focuses on the foundations of HTML, CSS, JavaScript, and the Web platform; advanced frameworks and full-stack development are optional extensions.

1. **[HTML: HyperText Markup Language — MDN](https://developer.mozilla.org/en-US/docs/Web/HTML)**  
   The authoritative reference for HTML elements, attributes, semantics, and examples. Use it throughout the course when learning or checking HTML.

2. **[How to Build a Personal Webpage from Scratch](https://rutar.org/writing/how-to-build-a-personal-webpage-from-scratch/)**  
   A practical introduction to creating a personal website without relying on a complex framework. Useful for seeing how the basic technologies fit together.

3. **[Responsive Web Design Certification — freeCodeCamp](https://www.freecodecamp.org/learn/2022/responsive-web-design/)**  
   Interactive HTML and CSS exercises with immediate feedback. Recommended for students who want additional practice beyond the classroom examples.

4. **[Certified Full Stack Developer Curriculum — freeCodeCamp](https://www.freecodecamp.org/learn/full-stack-developer/)**  
   A comprehensive learning path covering a much broader range of web development topics. This is an optional, long-term resource for students interested in continuing beyond the scope of DE0824.

5. **[Frontend Developer Roadmap](https://roadmap.sh/frontend)**  
   A visual overview of frontend technologies and the professional development landscape. Use it to understand where the course topics fit, not as a checklist of everything you must learn.

6. **[Learn Web Development — MDN](https://developer.mozilla.org/en-US/docs/Learn_web_development)**  
   A structured, beginner-friendly curriculum covering HTML, CSS, JavaScript, accessibility, and practical web development. One of the best general companions to the course.

7. **[The Modern JavaScript Tutorial](https://javascript.info/)**  
   A detailed, freely available JavaScript textbook. It covers programming fundamentals, the DOM, browser events, and asynchronous programming, with explanations and exercises.

8. **[Learn Web Development — web.dev](https://web.dev/learn/)**  
   Modern courses on HTML, CSS, JavaScript, accessibility, and performance. Particularly useful for responsive design and understanding contemporary browser capabilities.

9. **[Pro Git, Second Edition](https://git-scm.com/book/en/v2)**  
   A free, comprehensive reference for Git. Begin with repositories, commits, and basic collaboration; advanced Git workflows can be explored later.

10. **[GitHub Skills](https://skills.github.com/)**  
    Short, hands-on courses for learning how to use GitHub, work with repositories, and collaborate on code. A practical complement to the Git command-line material.

11. **[Web Accessibility Tutorials — W3C WAI](https://www.w3.org/WAI/tutorials/)**  
    Authoritative guidance on accessible images, page structure, tables, forms, and navigation. Especially relevant when publishing cultural heritage and Digital Humanities resources for diverse audiences.

12. **[Responsible Use of GitHub Copilot](https://docs.github.com/en/copilot/responsible-use)**  
    Guidance on the limitations and responsibilities of AI-assisted programming. AI tools can help explain, generate, and debug code, but students must be able to understand, test, and explain the code they submit.

### Recommended Learning Approach

Start with the course materials and the MDN learning resources. Use freeCodeCamp for additional hands-on practice and JavaScript.info when more detailed explanations are needed. Consult reference documentation when solving specific problems rather than trying to memorize everything. GitHub Skills provides practical Git and GitHub exercises, while the remaining resources offer broader context and optional further study.

AI-assisted programming is permitted, but generated code must not replace understanding. Students are expected to verify results, use browser Developer Tools, read error messages, and explain the HTML, CSS, and JavaScript in their own work.
