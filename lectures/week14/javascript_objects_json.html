1. From titles to structured records

Our previous catalogue stored only strings. But a bibliographic record also has an author, a publication year and a language. Four parallel arrays would be difficult to keep synchronized. An object groups related values under named properties.

Week 13: only titles

const books = ["Hamlet", "Faust", "Mērnieku laiki"];
console.log(books[2]); // Mērnieku laiki

2. Objects: properties and values

A bibliographic record

const book = {
    title: "Mērnieku laiki",
    author: "Reinis un Matīss Kaudzītes",
    year: 1879,
    language: "Latvian"
};
console.log(book.title);       // Mērnieku laiki
console.log(book["year"]);     // 1879
book.language = "lv";         // Update a property
console.log(book.language);    // lv

Dot notation is the simplest way to access a known property. Bracket notation is useful when the property name is stored in a variable. Reading a missing property returns undefined. Objects are mutable even when assigned to a const variable.

A dynamic property name

const field = "author";
console.log(book[field]); // Reinis un Matīss Kaudzītes
console.log(book.publisher); // undefined

Predict: What is the difference between book.year, book["year"], and book["publisher"]? Verify in the Console.

3. Arrays of objects: a small digital library

An array organizes records in a sequence; each object describes one record. We reuse for...of from Week 13.

Structured catalogue

const books = [
    { id: 1, title: "Mērnieku laiki", author: "Reinis un Matīss Kaudzītes", year: 1879 },
    { id: 2, title: "Hamlet", author: "William Shakespeare", year: 1603 }
];
for (const book of books) {
    console.log(book.title + " — " + book.author);
}
console.log(books[0].title); // Mērnieku laiki

Historical data note: year is a simplified representative publication year in these examples. For serious scholarly metadata, distinguish first publication, edition, composition and translation dates.

4. Render structured records in the DOM

As in Week 13, changing an array does not automatically update the browser. A rendering function must create and update DOM elements. We use textContent for record values, not innerHTML.

One record card

function createBookCard(book) {
    const article = document.createElement("article");
    const heading = document.createElement("h3");
    const details = document.createElement("p");
    heading.textContent = book.title;
    details.textContent = book.author + " · " + book.year;
    article.append(heading, details);
    return article;
}
// Later: catalogue.append(createBookCard(books[0]));

Use replaceChildren() before rendering the current result set; otherwise repeated searches can duplicate records. Inspect the resulting <article> elements in Developer Tools.

5. Search records with familiar loops and conditions

We do not need a new array method to search. Convert the query and text to lowercase, check whether either title or author includes the query, and render matching records.

Search with for...of

function findBooks(books, query) {
    const matches = [];
    const term = query.trim().toLowerCase();
    for (const book of books) {
        const title = book.title.toLowerCase();
        const author = book.author.toLowerCase();
        if (title.includes(term) || author.includes(term)) {
            matches.push(book);
        }
    }
    return matches;
}

Predict: What happens when the search term is empty? Why does "Hamlet".toLowerCase().includes("ham") return true?

6. JSON: structured data as text

JSON (JavaScript Object Notation) is a text-based format for exchanging structured data. It resembles JavaScript object syntax, but is not a JavaScript object itself. JSON requires double-quoted property names and strings, and does not support functions or undefined.

Valid JSON text

[
  { "title": "Mērnieku laiki", "year": 1879 },
  { "title": "Faust", "year": 1808 }
]

Convert between values and text

const record = { title: "Faust", year: 1808 };
const jsonText = JSON.stringify(record);
console.log(typeof jsonText); // string
const restored = JSON.parse(jsonText);
console.log(restored.title); // Faust

JSON also supports arrays, numbers, booleans and null. Unlike JavaScript object literals, JSON cannot contain comments or trailing commas. JSON.parse() throws a SyntaxError for malformed JSON.

7. Events and individual records

An event handler receives an event object. For a simple button, event.target identifies the element where the event originated. For our catalogue, a button attached to each record reveals details; each handler can also refer directly to its book object.

A simple event target

const button = document.querySelector("#example-button");
button.addEventListener("click", function (event) {
    console.log(event.target);
});
// The catalogue below adds a button to each record card.

Later, data-* attributes and event delegation can help with larger lists. They are not required for this week's application.

9. Debugging and practice

  1. Required: Add a fourth book object containing title, author, year and language. Confirm that it appears in the catalogue.
  2. Required: Search by title and author, including different letter case. Explain the role of toLowerCase().
  3. Required: Explain why changing an object or array does not automatically update the displayed cards.
  4. Required: Convert a sample object to JSON text and back. Demonstrate one malformed JSON example.
  5. Optional: Add a language filter using a loop and condition.
  6. Optional: Sort by year using an approach you can explain, or add a record count grouped by language.
Common mistakes: books.title instead of books[0].title; misspelled property names returning undefined; attempting toLowerCase() on a missing property; missing replaceChildren(); malformed JSON; or forgetting to render after a data change. Use the Console and Elements panel to diagnose each.

Exit question: Explain the distinction between a JavaScript object, an array of objects, JSON text, and the HTML elements created from those records.
