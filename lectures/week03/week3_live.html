Good use for section tag

Section tags are used to group related content together. In this case, we are using a section tag to group the main content of the Week 3 Live Demo. This helps improve the structure and accessibility of the webpage.

Good use for article tag

Article tags are used to define a self-contained piece of content that would make sense on its own. In this case, we are using an article tag to define a single article within the main content. This helps improve the structure and accessibility of the webpage.

Good use for hr tag

The hr tag is used to create a horizontal rule, which visually separates content. In this case, we are using an hr tag to separate the two sections of the main content. This helps improve the readability and organization of the webpage.
