Good use for section tag

Section tags are used to group related content together. In this case, we are using a section tag to group the main content of the Week 3 Live Demo. This helps improve the structure and accessibility of the webpage.

Good use for article tag

Article tags are used to define a self-contained piece of content that would make sense on its own. In this case, we are using an article tag to define a single article within the main content. This helps improve the structure and accessibility of the webpage.

Generic Tags

Good use for hr tag

The hr tag is used to create a horizontal rule, which visually separates content. In this case, we are using an hr tag to separate the two sections of the main content. This helps improve the readability and organization of the webpage.

Generic tags

Generic tags are used to define a generic container for other elements. In this case, we are using a generic tag to group related content together. This helps improve the structure and accessibility of the webpage.

div tag

The div tag is a generic container for other HTML elements. It is often used to group elements together for styling or scripting purposes.

span tag

The span tag is a generic inline container for other HTML elements. It is often used to apply styles or add attributes to a portion of text.

Escape Characters

Escape characters are used in HTML to represent characters that have special meaning in the language. For example, the ampersand (&) is represented as & to prevent it from being interpreted as the start of an HTML entity.

Good use for escape characters

In this case, we are using escape characters to represent the ampersand (&) in the text. This helps ensure that the text is displayed correctly and does not interfere with the HTML structure.

List of Escape Characters

  • & - Ampersand
  • < - Less than
  • > - Greater than
  • " - Quotation mark
  • ' - Apostrophe
  •   - Non-breaking    space - use sparingly!
