JavaScript: Repetition, Loops, and Control Flow

From choosing which code runs to repeating instructions: switch statements, while and for loops, early exits, and debugging.

Connection to Weeks 9–10: You already know variables, expressions, comparisons, Boolean values, and if/else. This week, you will reuse these concepts to control repeated execution. Arrays come in Week 13; functions and introductory DOM events come in Week 12.

Learning goals: read and write switch, while, do...while, and for; explain a loop's stopping condition; use break and continue; predict output; and diagnose off-by-one and nonterminating loops.

1. Why repeat instructions?

Imagine checking publication years in a historical newspaper collection. We could write console.log(1918), then console.log(1919), and so on. But a program should describe the pattern, not duplicate every instruction. A loop repeats a block of code while its controlling condition permits it.

First, one more way to choose among alternatives: the switch statement.

2. Switch: several choices for one value

Like Week 10's if...else if, switch selects a branch. It is convenient when comparing one expression with several exact values. Matching uses strict equality semantics (similar to ===).

Classify an archive document

const documentType = "letter";
switch (documentType) {
    case "letter":
        console.log("Correspondence");
        break;
    case "newspaper":
        console.log("Periodical");
        break;
    case "book":
        console.log("Publication");
        break;
    default:
        console.log("Unknown document type");
}

break exits the switch. Without it, execution continues into following cases, even when their labels do not match. The default branch is optional.

Intentional case grouping

const month = 11;
switch (month) {
    case 12:
    case 1:
    case 2:
        console.log("Winter");
        break;
    case 3:
    case 4:
    case 5:
        console.log("Spring");
        break;
    default:
        console.log("Another season");
}

Predict: What happens if you remove break after "Correspondence" in the first example? What if documentType is "map"? Try both in the Console.

3. While: repeat while a condition is truthy

A while loop checks its condition before each iteration. If it is false initially, the body never runs. An iteration is one execution of the loop body.

Print a short historical timeline

let year = 1918;          // Starting value
while (year <= 1923) {   // Continue while true
    console.log(year);
    year++;              // Change the value
}
// Output: 1918, 1919, 1920, 1921, 1922, 1923

The loop needs an initial value, a condition, and a way to make progress toward termination. Here year++ is shorthand for year = year + 1. We can also use year += 2 to advance by two.

Infinite-loop risk: if you forget year++, year <= 1923 stays true. A tight infinite loop can freeze a browser tab. Read and reason about this error rather than running it unbounded.

Predict: If year starts at 1925, how many times does the body execute? Change the initial value and check.

4. Do...while: execute first, check afterward

Runs once even when the condition is false

let count = 10;
do {
    console.log(count);
    count++;
} while (count < 5);
// Output: 10

do...while always executes its body at least once. It is less common than for and while, but useful when the first action must happen before checking whether to repeat.

5. For: a compact counter-controlled loop

A for loop places three pieces together: initialization (once), condition (before each iteration), and update (after each completed iteration).

Same timeline with for

for (let year = 1918; year <= 1923; year++) {
    console.log(year);
}

Use for when a counter and its progression naturally describe the repetition. Use while when continuation depends on a condition that is not necessarily a fixed number of steps. Both can express many of the same algorithms.

6. Break and continue: control individual iterations

Inside a loop, break exits the loop immediately. continue skips the rest of the current iteration and proceeds toward the next one. In a for loop, its update expression still runs.

Skip a year and stop early

for (let year = 1918; year <= 1925; year++) {
    if (year === 1920) {
        continue; // Do not print 1920
    }
    if (year === 1923) {
        break;    // Stop before printing 1923
    }
    console.log(year);
}
// Output: 1918, 1919, 1921, 1922

Be careful: using continue in a while loop before updating its counter may cause a nonterminating loop.

7. Practical application: historical dates

We can now combine Week 10 conditionals with Week 11 repetition. This example counts years divisible by four in a selected interval. It is an arithmetic exercise, not a complete calendar leap-year rule.

Count matching years

let matchingYears = 0;
for (let year = 1900; year <= 1950; year++) {
    if (year % 4 === 0) {
        matchingYears++;
        console.log("Match:", year);
    }
}
console.log("Total:", matchingYears); // 13

% returns the remainder. A remainder of zero means that the number is divisible by four. Notice that the counter is declared outside the loop so that its value accumulates across iterations.

8. Debugging repeated execution

Open Developer Tools → Sources, set a breakpoint inside a loop, and step through successive iterations. Watch the counter in the Scope panel or use console.log() to inspect values. For script-file examples, remember to reload after editing.

SymptomLikely causeInvestigation
One extra result<= instead of <Inspect the boundary value.
No outputCondition false initiallyInspect the initial counter and comparison.
Never stopsCounter not updated or moves in wrong directionTrace whether the condition can become false; do not execute an unbounded example.
Unexpected extra switch messagesMissing breakInspect case fall-through.

Find the off-by-one error

// Intended: print five values, 0 through 4
for (let i = 0; i <= 5; i++) {
    console.log(i);
}
// Fix: replace i <= 5 with i < 5

Debugging procedure: predict the result, inspect actual output, identify the first unexpected iteration, change one expression, and test again.

9. Practice exercises

  1. Predict (required): What does for (let i = 1; i < 5; i += 2) { console.log(i); } print? Explain each step before running it.
  2. Modify (required): Print every fifth year from 1900 through 1950 inclusive. Try both for and while.
  3. Combine (required): Count years between 1900 and 1950 inclusive that are divisible by four. Predict the total before checking in the Console.
  4. Optional challenge: Print years from 1900 onward, skip years divisible by five, and stop before 1940. Use both continue and break.

Self-check: Can you explain exactly when a loop starts, checks its condition, updates its counter, and stops? Can you explain the difference between break in a switch and in a loop?
