CSS Basics

CSS (Cascading Style Sheets) is a style sheet language used for describing the presentation of a document written in HTML.

This is a simple example of a webpage with some basic CSS styling.

Additional Information

CSS allows you to apply styles to HTML elements, such as colors, fonts, spacing, and layout. It can be included in the HTML document in three ways: inline styles, internal stylesheets, and external stylesheets.

In this example, we have used an inline style to change the color of the text in the second paragraph to red. You can also use internal or external stylesheets for more complex styling.

For more information on CSS, you can refer to the MDN Web Docs on CSS.
