1. Why collections?

A library catalogue has many titles. Writing a different variable for each title is difficult to maintain. An array is an ordered collection of values stored under one variable. We begin with strings; Week 14 will introduce records containing several fields.

2. Arrays: one variable, several values

Create an array and inspect it

const books = ["Hamlet", "Faust", "Mērnieku laiki"];
console.log(books[0]);     // Hamlet
console.log(books[1]);     // Faust
console.log(books.length); // 3

Array positions are called indices. JavaScript starts counting at zero, so an array of length 3 has valid indices 0, 1, and 2.

Index 0Hamlet
Index 1Faust
Index 2Mērnieku laiki

Reading a missing index returns undefined. The final element of a nonempty array is books[books.length - 1], not books[books.length].

Change the collection

books.push("The Trial");   // Add to the end
console.log(books.length); // 4
books[1] = "The Odyssey"; // Replace an element
const removed = books.pop(); // Remove and return last
console.log(removed);      // The Trial

push() and pop() mutate the existing array. A const variable cannot be reassigned to a different array, but the array it refers to can still be changed.

Predict: After the example above, what are books[1], books.length, and books[books.length - 1]? Check in the Console.

3. Process every item with a loop

Week 11 introduced for loops. Now the counter is an array index, rather than a year.

Index-based iteration

for (let i = 0; i < books.length; i++) {
    console.log(i, books[i]);
}

Value-based iteration

for (const book of books) {
    console.log(book);
}

Use for when you need the index; use for...of when you only need each value. for...of is a new loop syntax, not an array method. We will leave methods such as map(), filter(), and reduce() for later study.

Predict: How many lines print for an empty array []? What happens if the condition is i <= books.length?

4. From an array to the DOM

The array exists in JavaScript memory. The user sees HTML elements in the browser. These are not automatically synchronized: changing the array does not by itself change the visible page.

Array in memory → renderBooks() → DOM list elements → Visible page

HTML target

<ul id="book-list"></ul>

Render the current collection

const list = document.querySelector("#book-list");

function renderBooks() {
    list.replaceChildren(); // Clear old list items

    for (const book of books) {
        const item = document.createElement("li");
        item.textContent = book;
        list.append(item);
    }
}

renderBooks();

replaceChildren() clears the previous display. createElement() creates a new DOM element; textContent inserts plain text; append() adds it to the list. Avoid inserting user-entered strings through innerHTML.

Debugging: Remove list.replaceChildren() and call renderBooks() twice. Why are titles duplicated? Restore the line and inspect the DOM in Developer Tools → Elements.

5. Reading user input and handling events

Week 12 introduced click. A text field also produces input events while its value changes. A change event typically fires when the user commits a change; its timing depends on the control. A form produces a submit event when submitted, including when Enter is pressed in a suitable single-line field.

EventTypical use
inputUpdate a live preview or character count as someone types
changeReact when a control's value is committed
submitProcess and validate a form entry

Try it: live character count

0 characters

The input listener updates the count without submitting a form.

Input event

const previewInput = document.querySelector("#preview-input");
const previewCount = document.querySelector("#preview-count");

previewInput.addEventListener("input", function () {
    previewCount.textContent =
        previewInput.value.length + " characters";
});

Form submission

<form id="book-form">
    <label for="book-title">Book title</label>
    <input id="book-title" type="text" required>
    <button type="submit">Add title</button>
</form>

Validate, update the array, then render

const form = document.querySelector("#book-form");
const titleInput = document.querySelector("#book-title");

form.addEventListener("submit", function (event) {
    event.preventDefault(); // Stay on this page

    const title = titleInput.value.trim();
    if (title === "") {
        return;
    }

    books.push(title);
    renderBooks();
    titleInput.value = "";
});

The browser may reject an empty required field before a submit event fires. The JavaScript trim() check additionally rejects whitespace-only titles. preventDefault() prevents the form's usual navigation/reload.

9. Looking ahead: structured records

Today an array stores strings such as "Hamlet". A real catalogue also needs author, year, and other metadata. In Week 14 we will represent each book as an object, store objects in arrays, and explore JSON as a way to exchange structured data.
