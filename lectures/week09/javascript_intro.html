Week 9 goal: understand what JavaScript does, execute basic code in the browser, attach a .js file to HTML, use let and const, recognize common data types, calculate expressions, and diagnose simple mistakes with Developer Tools.

Connection to Weeks 1–8: HTML described our archive records, and CSS arranged and styled them. JavaScript adds the ability to calculate and make decisions. Today we focus on the fundamentals of programming; substantial DOM manipulation and event handling come later.

1. Why introduce a programming language?

Imagine a digital archive page listing historical newspapers. With HTML, we mark up the records; with CSS, we organize them into responsive cards. What if we also need to count the records, calculate an average, check whether an item matches a query, or update the results when someone selects a filter?

HTML answers: What is here?

Headings, text, links, forms, and document structure.

CSS answers: How does it look?

Colors, typography, spacing, layout, hover effects, and animation.

JavaScript answers: What happens?

Calculations, stored values, decisions, repeated operations, and programmable interaction.

JavaScript is a general-purpose programming language that browsers can execute. It was first created in 1995 at Netscape by Brendan Eich; its standardized language specification is known as ECMAScript. Despite their names, JavaScript and Java are distinct languages. JavaScript also runs in environments outside web browsers.

A useful distinction for the rest of this course: JavaScript is a language; the DOM and methods such as document.querySelector() belong to browser APIs used from JavaScript. We will return to this distinction when we begin changing pages with code.

Discuss: Is changing a card's color on hover necessarily a JavaScript task? No: CSS already supports this. Is calculating the average number of pages across a collection a natural JavaScript task? Yes.

2. First steps: the browser Console

Open this page in a browser, press F12 (or use the browser menu to open Developer Tools), and select Console. The Console can evaluate JavaScript you type and display diagnostic messages. You may need to enable pasting in the Console if the browser protects against unexpected pasted code; for this exercise, type the short examples yourself.

Try one line at a time

2 + 3
10 * 4
"Riga"
"Digital" + " Humanities"
console.log("Hello, JavaScript!");
Observe: the Console may display the value of an entered expression. console.log() explicitly prints a message; its own return value is undefined, which some consoles show after the message.
Console — illustrative output
> 2 + 3
5
> "Digital" + " Humanities"
'Digital Humanities'
> console.log("Hello, JavaScript!")
Hello, JavaScript!
undefined

Three new words: a value is data such as 5 or "Riga"; an expression is code evaluated to produce a value, such as 2 + 3; a statement is an instruction or declaration, such as const count = 5;. A program consists of JavaScript code that is executed according to the language's rules.

Predict, then test: what is the result of 10 + 5 * 2? What changes when you use (10 + 5) * 2? Parentheses can change the order of operations.

3. JavaScript inside an HTML page

Like CSS, JavaScript may be included directly in an HTML document or placed in its own file. For our live coding, prefer two small files: one for the HTML document and one for JavaScript.

📁 week09/

📄 index.html

📄 script.js

File 1: index.html

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First JavaScript</title>
    <script src="script.js" defer></script>
</head>
<body>
    <h1>Learning JavaScript</h1>
    <p>Open the browser Console!</p>
</body>
</html>

File 2: script.js

// My first JavaScript file
console.log("My JavaScript file is running!");

The <script> element references the JavaScript file using src, a path relative to the HTML document. The defer attribute tells the browser to download this classic external script without blocking HTML parsing and execute it after the document has been parsed, before DOMContentLoaded. We will use this pattern in later lessons.

JavaScript may also be written directly between <script> and </script> tags, but separating it from the HTML usually makes our examples easier to read and maintain.

Live-coding checkpoint: create both files, open the HTML file in the browser, inspect the Console, and then change the message in script.js. Reload the page. Do you see the new message?

Common problem: if script.js is actually named scripts.js, the file cannot be loaded. Inspect the Console or Network panel and check the filename and relative path. If Developer Tools show unrelated page-extension warnings, focus first on errors tied to your files.

4. Values, variables, and constants

Programs frequently need to remember information. A variable is a named binding that gives us a way to refer to a value. Choose names that convey meaning rather than using x everywhere.

An archive record count

const collectionName = "Historical Photographs";
let recordCount = 12;

console.log(collectionName);
console.log(recordCount);

recordCount = 15;
console.log(recordCount); // 15
SyntaxMeaningWhen to use
const collectionName = "Maps";Declare a binding and initialize it. It cannot be reassigned.Preferred when reassignment is not needed.
let recordCount = 12;Declare a binding whose value can be reassigned.When a value is expected to change.
recordCount = 15;Assign a new value to an existing binding.Update a variable previously declared with let.

= means assignment here, not a mathematical claim that two things are equal. The older var syntax exists, but we will use const and let in our exercises.

Why not reassign a constant?

const archiveName = "Riga Maps";
// archiveName = "Riga Photographs"; // Error if uncommented
A const binding cannot be reassigned. It does not mean that an object or array stored in a constant can never be modified; we will examine structured data later.

Names matter: recordCount and recordcount are different identifiers. Prefer descriptive names such as documentCount, totalPages, and averagePages.

Predict: What happens if we change let recordCount = 12 to const recordCount = 12 and leave the later assignment in place? Test and read the error in the Console.

5. Data types: not all values are the same

JavaScript values have types. The same characters can mean different things depending on how they are written.

TypeExampleExplanation
number42, 3.14Ordinary numeric values, with or without a decimal part.
string"Riga", '1920'Text enclosed in quotation marks.
booleantrue, falseOne of two logical values; useful for conditions later.
undefinedundefinedA value often found when a variable has been declared but not initialized.
nullnullAn intentionally specified absence of a value.

Inspect values with typeof

console.log(typeof 42);       // "number"
console.log(typeof "42");     // "string"
console.log(typeof true);     // "boolean"

const publicationYear = 1920;
const yearAsText = "1920";
console.log(typeof publicationYear);
console.log(typeof yearAsText);

JavaScript is dynamically typed: a binding declared with let can later refer to a value of a different type. This flexibility also means programmers must pay attention to the types involved in expressions.

Good to know, not needed today: JavaScript also has arrays, objects, bigint, symbol, and other behaviors surrounding types. We will study collections and objects near the end of the course. The surprising typeof null === "object" result is a historical language quirk, not something to memorize this week.

6. Arithmetic and expressions

An operator combines or transforms values. Start with arithmetic that works much like familiar mathematics.

OperatorMeaningExample result
+Addition (or string concatenation)10 + 3 → 13
-Subtraction10 - 3 → 7
*Multiplication10 * 3 → 30
/Division10 / 4 → 2.5
%Remainder10 % 3 → 1
**Exponentiation2 ** 3 → 8

Compute a collection statistic

const totalPages = 240;
const documentCount = 8;
const averagePages = totalPages / documentCount;

console.log("Average pages:", averagePages); // 30
console.log("Extra pages:", totalPages % 7); // 2

Expressions are evaluated according to operator precedence, so multiplication normally happens before addition. Parentheses make the intended calculation explicit.

Operator precedence

console.log(10 + 5 * 2);   // 20
console.log((10 + 5) * 2); // 30

Predict and change: try different values for totalPages and documentCount. What changes in averagePages? What happens if you divide 240 by 0? JavaScript numbers can also represent Infinity; this is a value, not a thrown exception.

7. Strings and the meaning of +

The plus operator has more than one use. If string concatenation is involved, it can combine text rather than add numbers. This is one of the first behaviors that new programmers need to recognize.

Three similar-looking expressions

console.log(10 + 5);           // 15
console.log("10" + 5);         // "105"
console.log(Number("10") + 5); // 15
Why? "10" is a string, not a number. The function Number() can convert a numeric string into a number, but not all text can be converted successfully.

Build a message using values

const city = "Riga";
const recordCount = 15;

console.log(city + " archive: " + recordCount + " records");

// Template literals use backticks (optional for Week 9):
console.log(`${city} archive: ${recordCount} records`);

For now, either form is acceptable. The important idea is that text and numbers are different types even when they look similar on the screen. Later, this distinction will matter when reading values from HTML form inputs.

Check your understanding: what does "5" + "5" produce? What does 5 + 5 produce? Use typeof on both results.

8. Comments and readable programs

Comments help readers understand the purpose of code. JavaScript ignores comments during execution.

Single-line and multi-line comments

// Number of catalogued manuscripts
const manuscriptCount = 25;

/* This calculation estimates the number of pages
   when each manuscript contains 12 pages. */
const estimatedPages = manuscriptCount * 12;

console.log(estimatedPages);

Use comments to clarify why something is done. Good variable names often eliminate the need for comments that merely repeat the code. Indentation and consistent spacing also make a program easier to follow.

9. A simple debugging method

Code frequently fails when learning. A useful debugging process is: observe the result → read the message → identify the line → formulate a cause → make one change → run again. Do not immediately rewrite the entire program.

Observe→Locate→Explain→Fix & test
ProblemExampleWhat to investigate
SyntaxErrorconsole.log("Riga);Unclosed quotation mark: the source is not valid JavaScript syntax.
ReferenceErrorconsole.log(documentCountt);Misspelled or undeclared identifier. Compare exact names and capitalization.
TypeErrorconst n = 5; n = 6;Attempted reassignment of a constant binding.
Wrong result, no exception"10" + 5 produces "105"The program executed, but the types or operation do not match the intended computation.

Deliberately break your program: introduce one mistake, read the complete browser error (including the source line), fix it, and reload. Repeat with a different mistake. Debugging is part of programming, not a separate activity.

11. Guided practice: digital collection statistics

Required exercise (10–15 minutes). Begin with the simple two-file project from Section 3. In script.js, store some facts about a digital collection and compute results.

Starting point — complete and modify this program

const collectionName = "Historical Newspapers";
let documentCount = 12;
const pagesPerDocument = 24;

const totalPages = documentCount * pagesPerDocument;

console.log(collectionName);
console.log("Documents:", documentCount);
console.log("Estimated pages:", totalPages);
  1. Required: change the collection name and choose meaningful numbers for your collection.
  2. Required: calculate another statistic using an arithmetic operator (for example, half the number of documents, or the average pages per document).
  3. Required: inspect the types of collectionName and documentCount with typeof.
  4. Required: increase documentCount before calculating totalPages, then predict the output before reloading.
  5. Required: deliberately misspell a variable and use Developer Tools to locate and correct the error.
  6. Optional challenge: assign the page count as a string, such as "24", and try both multiplication and addition. Explain the differences and use Number() where appropriate.

Important: A value computed using const totalPages = ... is not automatically recalculated when you later change documentCount. Put the change before the calculation if you want the new value reflected. JavaScript instructions execute; they are not spreadsheet formulas that recalculate themselves.

Completion criterion: you can explain what each statement does, what values are stored, which expressions are evaluated, why their results have particular types, and where to look when the program does not work.

12. Check your understanding

Predict the result before opening each answer. If unsure, type the code into the Console and compare your explanation with the result.

Question A: multiplication and addition

console.log(4 + 3 * 2);
Show answer A

10. Multiplication takes precedence over addition: 4 + (3 * 2).

Question B: reassignment

let records = 10;
records = records + 5;
console.log(records);
Show answer B

15. The second statement evaluates the old value plus 5, then assigns the result to the same variable.

Question C: string versus number

console.log("7" + 3);
console.log(typeof ("7" + 3));
Show answer C

"73", then "string". The plus operator concatenates when one operand is a string, converting the other operand to text.

Question D: a common conceptual trap

let documents = 5;
const pages = documents * 10;
documents = 8;
console.log(pages);
Show answer D

50, not 80. The value of pages was calculated when the second statement executed and does not automatically change afterward.
