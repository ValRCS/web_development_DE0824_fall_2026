JavaScript: Branching and Logic

From evaluating expressions to making decisions: comparisons, Boolean values, if, else, and logical operators.

Course homeWeek 9 JavaScript introductionComparisonsBranchingLogicDemoPracticeReferences

Connection to Week 9: You already know variables, types, expressions, console.log(), and how to load script.js using defer. This week you will use those values to decide which instructions execute.

Learning goals: predict comparison results; read and write if, else and else if; combine conditions with AND/OR/NOT; explain truthy/falsy; and debug branch boundaries in the browser Console.

1. Why do programs need decisions?

A digital archive may contain records from many periods and languages. A program needs to decide whether a record belongs to a selected collection. Unlike HTML structure or CSS appearance, this is conditional execution: the program follows different paths depending on values.

2. Comparisons produce Boolean values

A comparison is an expression whose result is either the Boolean value true or false. This builds on Week 9 expressions.

Try in the Console

let publicationYear = 1925;
console.log(publicationYear > 1900);   // true
console.log(publicationYear < 1900);   // false
console.log(publicationYear >= 1925);  // true
console.log(publicationYear <= 1924);  // false
console.log(publicationYear === 1925); // true
console.log(publicationYear !== 1925); // false
OperatorMeaning
>, <Greater than, less than
>=, <=Greater/less than or equal
===, !==Strict equality, strict inequality

Do not confuse: = assigns a value; === compares values without converting their types. == also exists, but performs type conversion in some cases; prefer === for these exercises.

Predict: What does 1925 === "1925" produce? Why?

3. Boolean values and conditions

true and false are Boolean values, not quoted strings. A condition is an expression evaluated to determine which statements execute.

Store a comparison

let year = 1925;
let isHistorical = year < 1940;
console.log(isHistorical); // true
console.log(typeof isHistorical); // "boolean"

4. First branch: if

An if statement executes its block only if its condition is truthy. Braces group the statements that belong to that branch.

One conditional action

let publicationYear = 1925;
if (publicationYear < 1940) {
    console.log("Historical publication");
}
console.log("Classification complete");

Predict: Which messages appear for publicationYear = 1950? Change the value and test.

5. Two alternatives: if...else

Use else for the alternative when the condition is false. Exactly one of the two branches runs.

Two possible messages

let pages = 80;
if (pages >= 100) {
    console.log("Long document");
} else {
    console.log("Shorter document");
}

Try 99, 100 and 101. Notice that the boundary value 100 is included by >=.

6. Multiple alternatives: else if

Conditions are checked from top to bottom. The first matching branch runs, and the remaining alternatives are skipped.

Classify a publication year

let year = 1925;
// Simplified example: valid positive CE years only.
if (year < 1900) {
    console.log("Before 1900");
} else if (year < 2000) {
    console.log("1900–1999");
} else {
    console.log("2000 or later");
}

Test: 1899, 1900, 1999, 2000. What happens if you reverse the two conditions? Why is order important?

7. Combine conditions: AND, OR, NOT

&& means AND (both conditions must be true); || means OR (at least one must be true); ! negates a Boolean value.

Archive collection criteria

let year = 1925;
let language = "lv";
if (year >= 1900 && year < 1940) {
    console.log("Within the date range");
}
if (language === "lv" || language === "en") {
    console.log("Supported language");
}
if (!(language === "lv")) {
    console.log("Not Latvian");
}

JavaScript evaluates && and || from left to right and may short-circuit: it skips evaluating the right side if the left already determines the result. These operators can return operands other than Booleans; in our examples, each operand is a comparison.

8. Truthy and falsy values

In an if condition, JavaScript converts the value to a Boolean. Common falsy values include false, 0, "", null, undefined, and NaN. Other values are generally truthy, including the nonempty string "false".

Check whether a title is present

let title = "";
if (title) {
    console.log("Title provided");
} else {
    console.log("Title missing");
}

An empty string is falsy, but a string containing spaces is truthy. For user input, use title.trim() when whitespace-only input should count as empty.

10. Practice and debugging

  1. Predict: For let year = 1940;, what does year < 1940 return? What about year <= 1940? Check in Console.
  2. Modify: Copy the if...else if...else example to script.js. Change the boundaries so the middle category covers 1918–1990 inclusive. Test 1917, 1918, 1990, 1991.
  3. Combine: Print "Selected" only for Latvian records from 1900 through 1939 inclusive. Test both the year and language boundaries.
  4. Debug: Why is this wrong? if (language = "lv"). Replace assignment with a strict comparison and observe the difference.

Optional challenge: Add a third condition pages >= 10 to your collection filter. Explain why a record fails when one criterion is false.
