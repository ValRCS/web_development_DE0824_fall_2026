Inline example

Some elements by default use inline layout, such as Link to Example Site and span elements start on same line and go to the next line after overflow. Inline elements do not start on a new line and only take up as much width as necessary.

Adjusting display from block to inline and vice versa

Paragraphs are block elements by default, which means they start on a new line and take up the full width available. You can change their display property to inline or inline-block to alter their layout behavior.
